> 用途：每次出新卡池可套用此框架，快速判断"该抽谁 / 能攒多少 / 值不值"。凡标注【待核实】的为需要在游戏内确认的数字，凡【官方】的为公告白纸黑字确认。

## 二、收入模型（大小月卡已买）
### 确定收入（已核实）
- **小月卡 = 90 蔷薇石/日**（=2700/月）。
- **大月卡 = 战令**（特许证）：当期奖励=**体质系黑券往日之影「完全防护」**（特许券兑换）+ 黑格专属挂饰（征服之证立得）。**几乎不给直接蔷薇石**；来一杯金币约 +8（领航4+征服4）。
- **每日任务（今日风向标/搞事计划簿）= 60 蔷薇石/日**（单个任务10，6个）。**金砖、深渊/水手之家宝箱不计入**。
- **月光石 → 蔷薇石 = 1:1**（现有1214 → +1214；还能上架贸易场）。
- **1抽 = 160 蔷薇石**（已核实）。
- **新手池「欢迎新船长」**：十连8折，**40抽保底必得1位黑券船员，首抽不歪**（≠角色池80保底）。
- **公测一次性**：预约送**20抽** + 活动累计送**100抽**。
- **记忆重逢-深层：每周 1 次免费**（白嫖黑券船员的唯一捷径）。
- **活动/签到**：常给来一杯金币*10（7日）、蔷薇石*800（7日）、蔷薇石*1600 等，**波动大**，按月度浮动估算。

### 换算（已锁定）

- **到 10/1（≈35天）蔷薇石 = 18540 + 2700(小月卡30) + 2100(每日60×35) + 1214(月光石) = 24554 → ≈153 抽**。

## 三、白嫖模型（记忆重逢-深层）
**逻辑**：当期 UP 黑券船员会进【记忆重逢-深层记忆】→ **免费拿到就是白嫖**。
- 每次免费 1抽，**50%** 出黑券船员/往日之影；**3抽**必得（船员或影）；**9抽**必得黑券船员。
- 你的目标本体（金券船员）& 专武（往日之影）都可能在当期深层里。
- 但**每周只有1次**，且当期内容随角色换人——**要在"她当UP的那2~3周"内多次白嫖**。

## 四、决策逻辑（每次出新池套这条）
1. **先拟 白嫖 目标**：预估她/他当UP期间，深层能白嫖 2~3 次（50%/3保底）→ 白嫖到本体的可能性。
2. **本体成本**：角色 UP池 80抽保底黑券（吃来一杯金币+蔷薇石），**先白嫖、缺多少补多少**。
3. **专武成本**：专武池 80抽保底黑券往日之影（吃噼噜的最爱+蔷薇石），**"40垫底会继承" → 一定要攒着留给主目标**。
4. **优先级**：主C本体/命座 ≥ 主目标专武 > 次要角色（辅助）专武。
5. **铁律**：**别为"非本命"的辅助/角色砸千抽级资源**；**保底是给主目标攒的**。
