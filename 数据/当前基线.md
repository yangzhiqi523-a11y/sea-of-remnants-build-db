# 当前 Meta 基线

版本：**2026-08**（以 **8/17 首赛季平衡重构（力量系）** 为当前强度基线；更早攻略需按版本日期淘汰）。

## 最终队伍目标
难度 3+ 稳定 farming，并推进高难自动化。

## 核心队伍

### 茉莉（Molly）
定位：主 C

终局路线：蚁妈（Ant Mother）→ 生命绑定（Life Bind）→ 香命缚者（Fragrant Life Binder）

所有决定都应支持此路线。

### 小斧头（Axe）
定位：副 C / 行动链支持

优先级：
- 为茉莉提供额外行动
- 支持伤害循环

### 饿猫（Hungry Cat）
定位：队伍辅助

最终细节待实测验证。

### 铁腕统领（Iron Wall）
定位：防御 / 稳定性

最终细节待实测验证。

## 备选 / 未来（box 候选）

### 盖尔（Gale）— 已持有
定位：强力通用「拉条 / 行动提前」辅助（动的越多动的越多）。
作用：加速主C（茉莉）出手，与「行动提前」船歌/骰子协同；可作辅助位或体系组件。详见 [角色/盖尔.md](../角色/盖尔.md)。

### 海葬（Sea Burial）— 已持有
定位：群攻向、无盾困难深渊主 C（社区称"群攻的神"，[B站](https://www.bilibili.com/video/BV11tGP6XEuA/)）。
作用：缺盾卫 / 特定高难时替换上场。

### 大王女 / 王女（Princess）— 下一池
定位：残血 / DOT 持续伤害向（待实装）。
作用：你计划在爱德华卡池之后投入的队伍；实装后按官方公告 + 社区攻略评估体系与配队。详见 [角色/大王女.md](../角色/大王女.md)。

## 决策规则
- 不为早期强度牺牲终局构建。
- 永久天赋需按终局评估。
- 装备机制 > 强化等级。
- 每个角色只有两个技能槽。
- 旧攻略必须对照当前版本复核。
- 不支持 / AI 生成的攻略拒收。
