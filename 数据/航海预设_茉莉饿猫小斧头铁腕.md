# 航海预设 · 茉莉/饿猫/小斧头/铁腕（挂机版 · 完整设定）
> 🎯 **开新航海前照这套配好；局内三选一照"必抓"拿；挂机=全自动，只偶尔手动铁腕放群盾。**
> 机制锚点（已官方核对）：**转职=出海 5/10/15 级各一次(共3次)，标签 3/3/6**；**行装=战斗掉落三选一，非抽卡**；**船员自带技能=被动/招牌/个人/防御 4类**（无"技能槽"取舍，职业技能由转职获得）。
> 队型：**茉莉(敏·协战双核·主C) + 小斧头(敏·印记单体·副C) + 饿猫(感知·群体追击易伤) + 铁腕(体·盾坦)**。★=必选/必抓。

## 团队协同（挂机版）
- **茉莉[共演] → 小斧头**（自动）。茉莉=小斧头每次攻击必协战，靠**叠暗影+暴击**放大；招牌技也是协战、吃同套增益。
- **铁腕**自动套盾/嘲讽，**仅手动放群盾**(余晖烬燃)挡电梯。
- **饿猫**=本队**唯一AOE**，靠[爪痕]易伤清小怪。
- ⚠️ 本队**偏单体**，多波小怪关 → 给饿猫补**群体/溅射**，给茉莉/小斧头补**单体爆发**。

## ① 茉莉（敏捷 · 协战双核 · 主C）
- **转职（5/10/15 三次）**：独行客学徒(初始) → 5级选 **缠命人**(暴击) → 10级选 **异香缠命人**(暴击·III)【★推荐，暴击/暗影放大协战】；15级可再补 **讨债人**(额外行动) 或 **蚁妈**(招牌技)。
  - 备选路线：讨债人→首席讨债人(额外行动/追猎)；**蚁妈→海礁蚁后**(招牌技=裂帛曲·协战，灌大招流)。

- **天赋(头脑强化·★必选)**：`水母天上飞`(掷骰→协战伤)、`彩虹通异梦`(协战伤+6%)、`飞鸟水里游`(暴伤+7%)；次选 `灵光潮涌`(协战行动提前9%)、`梦境交织`(个人技回50%能量)。

- **船歌(★必抓标签=协战/暗影/暴击/额外行动)**：`异香与夜的呢喃`(暴击率+10%暴伤+24%)、`女巫蹈足于夜`(暴击率+10%)、`幼蝶滋生飓风`(额外行动→强化点)、`工蚁没有休息日`(招牌技储存伤害)。

## 局内三选一 · 必抓优先级（出海时照这个选）
1. **标签吻合本队闭环** 最优先（茉莉=额外行动/招牌技/暴击；小斧头=招牌技/额外行动/暴击；饿猫=负面/固定伤害/强化骰；铁腕=护盾/受击/防御）。
2. **高稀有度(橙/金/闪光)** 优先；**闪光行装必拿**（属性更高）。
3. **带转职标签的船歌**优先（决定能否转职 = 定构筑方向）。
4. **强化骰**：输出位=输出增伤(聚浪/蝶陨/猛猛)、辅助=功能(锐牙)、坦克=生存(磐石)。
5. 看到上表★行装/船歌即拿（替掉低质件）。

> ⚠️ 挂机：**开局确保茉莉[共演]在小斧头**；铁腕设手动看时机放群盾；其余自动。
> 本队**偏单体**：多波小怪关优先给**饿猫**补群体/溅射，否则清怪会慢。
