# 航海预设 · 茉莉/饿猫/小斧头/铁腕（挂机版）
> 🎯 **开新航海前照这个配好；局内三选一照"必抓/优先"拿；挂机=全自动，只偶尔手动铁腕放群盾。**
> 队型：**茉莉(敏·协战双核·主C) + 小斧头(敏·印记单体·副C) + 饿猫(感知·群体追击易伤) + 铁腕(体·盾坦)**。
> 数据：官方公告 + SorWiki。★=挂机务必优先的无条件/稳定项；具体词缀数值以游戏内为准。

## 团队协同（挂机版）
- **茉莉[共演] → 小斧头**（自动；小斧头单点最频繁、攻击可吃）。茉莉=小斧头每次攻击必协战，靠**叠暗影+暴击**放大，招牌技也吃同套增益。
- **铁腕**：自动套盾/嘲讽；**仅手动放群盾**(余晖烬燃·全体守护之壁)挡电梯。
- **饿猫**：群体追击+[爪痕]易伤，给本队**唯一AOE**清小怪。负面(爪痕)由小斧头/茉莉/自身叠加。
- ⚠️ **挂机注意**：本队**偏单体**，AOE只有饿猫。若打多波小怪关，给**饿猫**补群体/溅射，**给茉莉/小斧头**补单体爆发。

## 局内三选一·必抓优先级（通用规则）
1. **标签吻合本队闭环**最优先（茉莉=额外行动/招牌技/暴击；小斧头=招牌技/额外行动/暴击；饿猫=负面/固定伤害/强化骰；铁腕=护盾/受击/防御）。
2. **高稀有度(橙/金/闪光)** 优先；**闪光行装**必拿（属性更高）。
3. **顺带转职标签**的船歌优先（决定能否转职 = 定构筑方向）。
4. **强化骰**：输出位拿输出增伤(聚浪/蝶陨/猛猛)、辅助拿功能(锐牙)、坦克拿生存(磐石)。
5. 看到上述**★毕业行装/必抓船歌**即拿（替掉低质件）。

> ⚠️ **挂机不选的话**：至少确保**开局把茉莉[共演]手动在小斧头**（若自动不会优先），并把**铁腕**设为手动看时机放群盾；其余交给自动。**本队偏单体**，多波小怪关优先给饿猫补群体/溅射。
