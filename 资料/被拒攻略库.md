# 被拒攻略库

用途：记录不可靠来源，标注拒收理由。

## 拒收标准
出现以下任一情况即拒收：
- 版本未知
- 技能名或数值错误
- 未经高难实测
- 纯理论、无证据
- 与官方更新冲突
- 社区反馈失败

每条被拒攻略需附理由。

## 评论区验证（毒攻略识别要点）
- 社区口碑两极化说明攻略**必须结合评论 / 实测**判断（如 [口碑裂成两半](https://www.toutiao.com/article/7673489646571078159/)）。
- 同一角色正反两说时需警惕，例如**盖尔**：一说〔T0·最多90%拉条〕，另一说〔**适配度一般**〕，且有"**被动暗改一刀**"事件（[TapTap](https://www.taptap.cn/moment/834389489093706836)）→ 不能当版本答案，需实测。
- **茉莉**有"加强之后的'讨债人'茉莉"（[B站](https://www.bilibili.com/video/BV1RNbz6VE3z/)）→ 旧强度攻略需按加强后重估。

### 毒攻略红旗（评论区 / 内容出现就警惕）
- 标题党"🔥XX 封神 / 速抄 / 秒杀全服"、无版本、无实测数字。
- 满嘴"必抽 / 必练"、不肯说缺点 / 适配度。
- 与官方数值 / 公告对不上，或被评论区指出"伤害不对"。
- 疑似 AI 批量生成、措辞泛泛无细节。

> 规则：宁可欠定论，也不采纳**未经实测 / 无版本 / 评论区不佐证**的来源。
