# 饿猫（希尔达 / Hungry Cat）
> 📌 **权威数据**：SorWiki 数据站 `/crew/emao`（社区数据，需对照官方验真）。常被视作**百搭辅助/易伤组件**。

## 定位
**群体追击副输出 + 易伤辅助**（黑券 5星 / 感知系·辅助·协攻）。

## 基础档案
流浪号 · 奥托皇亚 · 瞭望员 · 常驻 · 公测。

## 属性
- 生命 350/3950 · 攻击 20/181 · 防御 10/73 · 速度 108/108。
- 六维（1→6）：**感知16→56**(主) / 力量12→42 / 体质10→35 / 敏捷9→29 / 智力8→28 / 魅力6→21。

## 职业路线
机灵鬼学徒(1阶·感知·初始) → 蜜丸(2阶·推荐) → 蜜糖魔铳(3阶·推荐)。

## 技能
- **饿！（被动）**：用强化骰获1层[肚子咕咕](合4)；技能后消耗2层发动[喵喵狩猎]追击全体(攻30%/57%)+1层[爪痕]4回合(合3)；[爪痕]每层受伤+5%+负面总数×2%，单层上限14%。
- **上钩了（招牌·12能量）**：全体150%/300%伤害+1层[爪痕]；满层补[鱼骨脆了](被攻击后追加攻击者攻100%/200%伤)。
- **猫口夺食（个人）**：单体400%/800% + 2层[肚子咕咕]。
- **守势（防御）**：减伤，同属性反弹。

## 天赋（头脑强化）
水手本能(自选主属性职业技能)；璀璨闪光(下次攻击主目标+1爪痕，满层自身回3能)；猫猫拳(掷骰本场速度+2%/6.8%)；好吃的别跑(架势伤+10%/34%)；再来一口(回能效率+2.5%/8.5%)；有食同享(队友攻[鱼骨脆了]目标+5%)；又饿了(招牌技后全队行动提前8%)。

## 秘闻
#1 开战行动提前100%、首次个人技不结束回合｜#2 掷骰该次[鱼骨脆了]+攻20%至多200%｜#3 施加[鱼骨脆了]自获5层[专注]｜#4 [喵喵狩猎]命中爪痕/鱼骨脆了目标受伤+15%｜#5 每次[喵喵狩猎]我方掷骰永久+1至多3｜#6 [鱼骨脆了]触发3次立即[喵喵狩猎]+固定伤。

## 培养与配队
群体追击副输出+易伤辅助，靠[爪痕]按负面数增伤、满层转[鱼骨脆了]。适合**负面丰富队**，核心循环"掷骰攒2层肚子咕咕→个人技补层触发追击→叠满3层爪痕上鱼骨脆了→多段队友集火"。限制：强化骰供应少/无其他负面时追击爪痕上限下降；鱼骨脆了需后续攻击回本。
