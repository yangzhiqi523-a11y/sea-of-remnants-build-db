# 小斧头（Axe）

## 定位
副 C / 行动链支持。

## 转职路线 / 流派
- **流派**：暴击 / 追击（行动链）副 C；存在"转职暴击"路线。
- **推荐度**：中高；给茉莉提供额外行动、支持伤害循环。
- 参考：[小斧头转职选哪个](https://www.9game.cn/yiwangzhihai/11992898.html)、[小斧头·转职暴击指南](https://www.9game.cn/biji/1369191.html)、[小斧头二阶段学什么](https://www.18183.com/gonglue/202607/m5a7s7c4.html)。

## 研究结论（采集自公开来源，非最终定论）
- 技能搭配偏"高效输出 + 生存兼顾"；定位是给主C（茉莉）提供**额外行动**、支持**伤害循环**。
- 线索来源：[18183·技能搭配](https://m.18183.com/gonglue/202607/pse69dcm.html)、[豌豆荚·技能搭配](https://www.wandoujia.com/strategy/7152023438423680581.html)。
