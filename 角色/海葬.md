# 海葬
> 📌 来源：SorWiki 数据站 `/crew/haizang`（社区数据，需对照官方验真）。定位：**群体AOE法师 (可主C可副C)**。

## 定位
**清杂成长型群体AOE主输出**（黑券 5星 / 智力系·主攻）。

## 基础档案
船队·妄想剧团；阵营·托尼诺；职位·舞者；喜爱泉水；公测·常驻。

## 属性
- 生命 350→4412 · 攻击 20→229 · 防御 10→68 · 速度 87→87。
- 六维（1→6）：力量10→35 / 敏捷16→56 / 体质12→42 / **智力20→70**(主) / 感知10→35 / 魅力10→35。

## 职业路线
狂想家学徒(1阶) → 饲虫人(2阶) → 灾厄虫母(3阶)，全智力系。

## 技能
- **亡蝶（被动）**：额外行动伤害+10%/20%；敌方力竭(散怪/强敌/霸主)各获 2/3/5层[往生蝶]，上限25层；每耗5层往生蝶得1层[灵感]。
- **致逝者（招牌·14能量）**：全体攻450%/900%，场上每多1敌额外+30%。
- **安魂舞（个人）**：全体攻200%/400%；若已有5层往生蝶，立即耗5层**额外释放1次招牌技**(300%/600%，免能量，视为额外行动)。
- **守势（防御）**：减伤，同属性反弹。

## 天赋（头脑强化）
水手本能；璀璨闪光(技能后本次/下次攻击+30%，结算后+1层往生蝶)；再次起舞(每次额外行动按效果命中加伤4%/12%)；愿你安息(额外行动伤害+10%/30%)；为你哀悼(攻击+3%/11%)；无岸低语(用个人技后伤害+10级2回合)；解脱吧(对体力>50%敌伤害+24%)。

## 秘闻
航行开始+5层往生蝶；累计15层后技能伤害+15%可继承｜力竭时个人技CD重置｜额外行动获[汇聚](3倍加料概率+10%)｜招牌杀敌全体+200%攻(每场1次)＋攻+5级2回合｜[加料]额外20%×本场已耗往生蝶层数攻伤(至多60%)、获往生蝶时+2灵感｜力竭额外+1层往生蝶、耗往生蝶向全体施加[蝶蛹]。

## 往日之影
首选 **缎带泪**(黑券·关联海葬·2300)；坠落之瓶(紫·2145)/思维浪潮/蔚蓝叹息(蓝·1860)。

## 培养与配队
依赖散怪快速积累往生蝶→5层后个人技触发额外招牌技；多波次多目标关作群体主输出，资源转后续强敌。**限制**：纯单体首领且前无散怪时启动慢；过早放个人技会错过免费招牌技。输出前检查敌是否够、个人技前是否已5层、额外行动/群伤加成是否投入。

## 适配装备
主属性**智力**；先筛智力装备，再按部位/属性加成/固定效果/穿戴需求比较。
