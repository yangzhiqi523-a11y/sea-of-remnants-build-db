# 盖尔
> 📌 来源：官方公告 + SorWiki `/crew/gaier` + B站实测（`Alice萧宵·盖尔全方位测评`、`大块板砖·盖尔职业与技能选择`）。**2026-08-06 上线；08-17 进记忆重逢卡池 + 08-17 首赛季平衡（魅力系被调）**。

## 定位
**魅力系·核心辅助 = 加速拉条奶**（行动提前 + 输出增伤 + 群体续航）。黑券5星 / 魅力系·艺术先锋。给主C拉条+增伤+回血，**本队双C(敏)的最佳护航**。

## 基础面板（满级·视频实测）
- 攻击187 · 体力5300 · 防御68 · **速度108** · 主属性**魅力70**。
- 对比伊莎贝拉：攻击略低、血量略高、速度更快（魅力系里出刀偏快）。

## 核心机制 = 「根音」循环
- **被动·万众瞩目**：每消耗**5层[根音]→返还2层**(净-3)。触发时令其他我方**行动提前6%→9%(满级)**并获[摇滚狂奔]2回合；[摇滚狂奔]=技能**伤害倍率提升**(+8%/层，累积满级约**+48%**，视频实测)。
- **个人技·盛大登场**：全体附加伤害(满级≈攻击480%)+我方群回血(该伤20%+400，耗2层根音伤害+50%)；冷却3回合且**结束回合**。
- **招牌技·摇滚风暴(12能量)**：单体附加伤害+**全体行动提前**；耗根音额外伤害/提速(满级耗3层根音→全队提速30%)。
- **守势(防御)**：减伤同属性反弹。

## 职业技能组合（★视频推荐：**飞弦小夜曲 + 引路人独奏**）
- `飞弦小夜曲`：给敌挂[不和谐弦]，**队友攻击为其回根音**；用骰子加速(1骰=友方首攻回2层，2骰=首攻拿满3层)；配共鸣骰击破弱点→一口气大量回根音。
- `引路人独奏`：耗根音为**行动值最高(主C)**加速。开大须攒≥7层(为招牌技保3层)。
- **循环**：飞弦小夜曲挂不和谐弦 → 队友攻击回根音 → 攒够(≥7层) → 引路人独奏拉主C → 大招(耗3层)全队提速 → 再放飞弦小夜曲刷新不和谐弦回根音。
- ⚠️ **别带`轻快舞步`**(加移速9)：与引路人独奏组合**容易断根音**（零命无专武很缺根音）。满命/带专武不缺根音 → 才考虑轻快舞步加速。**推荐引路人独奏**。

## 转职方向（★3次转职 5/10/15）
- **主**：艺术先锋学徒 → **牧羊犬**(II·行动提前) → **无面放羊人**(III·行动提前)【拉条/提速核心，**未受8/17削弱**】。
- **副(凑正面标签)**：**先转一次纯白宠儿**(II)→ 取船歌助转 **纯白宠儿**(III·正面状态)。
- **凑标签技巧**：职业加成带1标签 + 艺术先锋职业2个正面标签 + 转职留1正面标签 + 摇正面状态技能 → 攒满正面状态标签。**推荐唱船歌凑标签**(而非浪费晶骸摇技能)，因纯白宠儿的「盛大开场」Buff值得拿；局内凑闪光/复合装备可省船歌给主C吃。
- ⚠️ **8/17 平衡**：纯白宠儿**正面状态堆叠(华丽谢幕)被砍上限** → 纯白宠儿只作**凑标签+盛大开场**，别指望无限堆叠；**主输出增益走牧羊犬/无面放羊人**(不受影响)。

- 盖尔=加速拉条奶+通用增伤，适合各种体系；与**敏捷双C(茉莉/小斧头)**最搭(拉条+增伤放大爆发)。
