# 游戏是什么 · 怎么玩 · 从哪学起
> 🧭 **先看这页建立整体认知**，再去看角色/配队/build——否则容易只见树木不见森林。
> 版本锚点：2026-08（8/17 首赛季平衡重构）。数据版本以游戏内+官方公告为准。

## 一句话
《遗忘之海》= 网易**海洋开放世界**冒险，核心是**航海「搜打撤」** + **肉鸽局内构筑** + **回合制四系职业战斗**，外加长线养成与多端互通。

## 核心循环（最重要）
**出海 → 👀搜 → 🎲构筑 → ⚔️打 → ⛵撤**
1. **出海**：驾船离开主城（奥托皮亚）进入海域/岛屿。
2. **搜**：探索、搜刮物资、奇珍、宝箱（风险与收益并存，越深入越肥也越危险）。
3. **构筑（局内肉鸽）**：每次出海=一局「**遗忘之旅**」，局内选 **船歌 / 行装 / 强化骰 / 技能晶骸 / 天赋** 构筑这一局。
4. **打**：**回合制**战斗，用四系职业体系（力量·溅射 / 智力·持续伤害 / 敏捷·追击暗影 / 魅力·正面状态）打掉敌怪/Boss。
5. **撤**：**返航带走收益**。搜得越深、越贪，收益越高，但翻车/失本风险越大——核心是**风险收益权衡**。
> 在"搜打撤"之上再叠加：主线推进、长线养成（船员/职业/船/黑券）、高难（大记忆之塔/噩梦深潜）与**冲榜**（"好梦杯"等）。

## 玩法模块
- **大世界海洋** + **主城**（奥托皮亚）+ **岛屿**（隐秘海：石像岛/密林岛/溪流岛/虫岛/佳酿溶洞）+ **小游戏**。
- **肉鸽局内**：遗忘之旅（每局随机构筑，见 `局内机制.md`）。
- **回合制战斗**：四系职业，见 `官方资讯与术语.md`。
- **高难**：大记忆之塔、噩梦深潜/无尽梦魇（含好梦杯大赛）。

## 养成线（长线）
船员（角色）、**四系职业/转职**、天赋、**船歌**、**行装/词缀**、**强化骰/技能晶骸**、**船只改装**、**黑券**（招募/六选一）。→ 详见各 `角色/`、`系统/`、`数据/` 页。

## 上手路径（阶段）
| 阶段 | 学什么 | 建议 |
|---|---|---|
| 0 认识 | 核心循环=搜打撤+局内构筑+养成 | 先懂"一局怎么打、怎么收益"，别只盯配队 |
| 1 推主线 | 主线推进解锁系统/区域；黑券六选一补缺口 | [官方新手攻略](https://cg.163.com/static/content/6a731aaa2ed0d6aa5c8a3e07) |
| 2 局内构筑 | 遗忘之旅每局选择（船歌/行装/强化骰/技能晶骸/天赋） | 见 `系统/局内机制.md` |
| 3 长线养成 | 船员/四系职业/转职、船只改装、词缀、黑券 | 你目前主要阶段 |
| 4 冲榜/高难 | 大记忆之塔/噩梦深潜、版本最优构筑、冲榜配队 | 你目前主要阶段 |
