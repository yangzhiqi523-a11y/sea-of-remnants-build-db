## 〇、一句话
《遗忘之海》= 网易**海洋开放世界**冒险，核心 = **远航清剿** + **肉鸽局内构筑** + **回合制六系职业战斗**，外加**金果子(大世界)等级**门槛、船员养成与**冲榜**，多端互通。

---

## 一、主循环与"局"（★忘遗忘之旅纠正）
- **出航 → 清剿/搜集 → 回合制战斗 → 返航** 为核心。
- **每"局" = 遗忘之旅**：**一次连续的大世界航行周目**（横跨各海域 + 主/郊/散岛），内含**清剿目标、霸主节点、营火、资源点**。★**不是**单个回合制战斗局，而是"航行 + 多场回合战"整局。
- **通关条件**：仅完成「白沙海」和「渡桥海」的挑战即可通关遗忘之旅。
- **清剿**＝**减负功能**：击败该区域的清剿目标 → 获得该区域内**除营地外所有敌怪的首胜奖励**；不是独立主线（主线＝船长任务）。★无"清剿/主线"双轨。
- **霸主**＝**局内节点**（岛屿霸主：剑刻家/疯老头穆雷/棋手巨像；另有海上霸主，不入清剿范围）。

## 二、金果子等级 = 大世界等级（1–7）
全局门槛（★纠正为"大世界等级"）：
- **≥4**：行装霸主掉落三选一随机出现**金装强化**选项；**船首像**解锁（7/23 延后至4）。
- **≥5**：部分岛屿怪/海怪难度下调；**清剿**解锁。
- **≥6/7**：「怪诞曲型号」号角初始阶级升为 2/4 阶。
- 升级条件：去除了「击败海上霸主」要求（金果子2 击败海上巨花除外）。

## 三、六系职业树（力量/敏捷/体质/智力/感知/魅力）
- 每系 = **I阶学徒(基础) → II阶分支 → III阶高阶**。★I阶上限5、II/III阶上限10 为*工具站(SorWiki)口径*，公告未明说。
- **转职** = 前置职业 + **标签数** + 职业任务。★标签数 **3 转 II 阶、6 转 III 阶**（7/23 由 4/4/8 下调），**非8/17**。
- **标签来源 = 晶骸技能 + 船歌**：先选适配**晶骸技能**，再**学一次对应标签船歌**即凑够首转（7/15 来信原文）。

### 六系定位 × 机制标签（★感知/体质纠正）
| 系 | 核心逻辑 | 机制标签 |
|---|---|---|
| 力量 | 溅射 / 低体力值爆发 | 低体力值 / 溅射 / 护盾 |
| 敏捷 | 追击(追猎)/暗影 + 额外行动 | 招牌技 / 暴击 / 额外行动 / 负面状态(水仙) |
| 体质 | 生存(护盾/防御/受击) | 受击 / 护盾 / 防御 |
| 智力 | 持续伤害(DOT) + 加料/灵感 | 持续伤害 / 强化骰 / 额外行动(饲虫人) |
| 感知 | 强化骰 / 固定伤害（★"好运"属钓命儿机制） | 负面状态 / 强化骰 / 固定伤害 |
| 魅力 | 正面状态 / 行动提前 / 治疗 | 行动提前 / 附加伤害 / 治疗 / 正面状态 |

> **I阶基础**：战斗狂学徒(力量)/独行客学徒(敏捷)/忠卫学徒(体质)/狂想家学徒(智力)/机灵鬼学徒(感知)/艺术先锋学徒(魅力)。II/III 分支见 `系统/职业体系与船歌机制.md`。

## 四、局内构筑（★矫正）
- 局内可拿：**行装 / 强化骰 / 船歌 / 技能晶骸·骰子晶骸(晶骸三选一) / 奇珍 / 祷石 / 职业天赋**。
- 进入方式：战斗掉落（霸主掉专属行装/奇珍/祷石）、清剿奖励、**三选一**、商店。
- ★**天赋属职业转职体系**（头脑强化树），**不是局内三选一**。

## 五、船员养成
- **等级**（出海经验，经验溢出会储存，升上限后继续提升）。
- **躯干保养**（★"突破"=躯干保养突破 6 阶；手部/躯干/腿部/关节 各5次保养+突破；每阶加生命/攻击/防御/伤害提升并附特效）。★旧称"四肢突破3阶"＝躯干保养Ⅲ阶；转职门槛航海团等级 16→15（7/23）。
- **头脑强化**（8项天赋树，强化条件依赖**躯干保养Ⅳ–Ⅵ阶**，耗大脸币/怪味凝胶等）。技能总等级上限 **Lv.15**（头脑强化10 + 往日之影5）。
- **船员秘闻**（6条，强化效果）。
- **往日之影**（共鸣属性装备）。

### 技能类型（★纠正）
- 船员自身技能 = **被动技 / 招牌技 / 个人技 / 防御** 四类；「职业」是"船员技能 vs 职业技能(Lv1–10)"的分类维度（*无投掷类*）。
- ★「两个技能槽」**官方公告与 SorWiki 均无"技能槽"说**，无法证实。

## 六、船只系统（★玩家身份=船长）
- **船只研发**（改装/强化，航海团41级解锁）。
- **船首像**＝**祈祷+守护**（祈祷:粗犷炮管/膛线改火炮弹匣&射击伤害；守护:效果有保证/腐蚀它/高难舞蹈/拒绝坏状态）。★「共鸣」是记忆/往日之影的共鸣属性，**非船首像**。
- **感召力**：船对不同属性船员增幅不同（如"流浪烟花号"敏捷/智力感召力更高）。
- **火炮岗位**（侧舷炮/船首炮/狙击炮），**火炮带技能**，乘员占岗位；适配炮型（火箭发射器/加农炮/连射狙）。
- 「船队图纸」「改造方案」＝石像岛船长任务/首次击败指定岛屿霸主；于奥托皮亚「**破产船坞**」向渣普船长提交建「**流浪烟花号**」。

## 七、行装（★非抽卡）
- **获取**：战斗掉落（清剿/岛屿霸主）→ **三选一** → **穿戴给船员**；可强化，分**紫/橙/金/闪光**，部分**自带职业标签**。
- **属性阈值**：行装**六属性阈值**需船员满足才正常生效；不满足 → **属性衰减**（★"衰减表现"官方未明文=伤害降或词缀失效，仅证"存在该机制"）。
- **金果子≥4** → 霸主行装三选一随机出**金装强化选项**（强化指定金色装备）。
- **商店**：卖掉没用的行装 → 买适配海螺（经济闭环）。

## 八、船歌 / 晶骸 / 奇珍 / 祷石
- **船歌**：带**标签**，决定能否转职（=选构筑方向）；208首见 `数据/船歌图鉴.md`；学一次耗**窃声螺碎片**（按属性：感知紫袖/魅力俏丽/敏捷油草/体质金壁/智力水渍，+白娇碎片通用，1–15次递增）。
- **晶骸**：技能晶骸/骰子晶骸（清剿掉落/晶骸三选一）；技能晶骸＝转职标签来源 + 技能升级材料。
- **奇珍**＝**特殊行装（非独立槽位）**：带固定词条、可穿多件同时生效；从霸主掉落 /「悠久的馈赠」解锁对应掉落。
- **祷石**：82颗，基础+感召触发；指定掉落（金堆旁=黄金巨蟹、林间守望=溪流岛铁翎巨枭…）；可在噩梦深潜生效。

## 九、高难 / 冲榜 / 记忆重逢
- **噩梦深潜**＝高难战斗（沉沦梦境环境、传奇挑战）。
- **无尽梦魇**＝噩梦深潜内的**积分挑战**（击败「人鱼·莫莉安」获噩梦深处钥匙→解锁）。
- **好梦杯**＝以"噩梦深潜·无尽梦魇"为主题的**分组排行赛事**（8/20预告；**8/24 04:00–8/30 23:59**，8/31 10:00 公布；组别:打作一团/盖尔初登场/饿猫最厉害/艾丝棒极了）。
- **大记忆之塔**＝**梦境入口**：每周完成噩梦深处**浅表梦境第1层**→进入大记忆之塔→开启**遗忘之海**通路→**记忆重逢**。
- **记忆重逢**（免费获船员/往日之影）：每完成浅表梦境第1/2/3层解锁**浅/中/深记忆**；深层记忆 50% 概率获黑券船员/往日之影，最多3次保底、9次保底1黑券船员。

## 十、船员获取
- **吧台招募（抽卡，用于 船员+往日之影）**：「来一杯」金币/银币；每10次必得紫券+、**每80次必得黑券**；公共吧台「这里不散场」/新手「欢迎新船长」(十连8折,40次)/「私人吧台」(限时,共享保底)/「噼噜的旧日秘藏」(往日之影)。
- **黑券6选1**：小斧头/饿猫/海葬/焦面上校/铁腕统领/伊莎贝拉（主线「初次记忆重逢」领取）。
- **霸主掉落**：击败石像岛霸主「剑刻家」→ 紫券船员剑刻家；票据商店兑换蹭船证。
- **定向招募**：公共吧台勾选定向 → 招募到黑券必为定向船员。

## 十一、资源速览
- **蔷薇石**（高级/充值货币）；**大脸币**（通用养成金币，躯干保养/头脑强化/招募）；**怪味凝胶**（特质/职业特性/闪光强化材料）；**海螺**（船员属性装+转职突破）；**黑券**（最高稀有度品级）。
- **金指的百宝屋**（售宝藏得大脸币、购宝藏多多/号角）；**宝藏商店**（购"怪诞曲型号"号角，初始阶级随金果子）；**票据商店**（票据/羽毛票据兑换）。
- ★「**悠久的馈赠**」（注意：非"久远的馈赠"）＝解锁霸主专属行装/奇珍掉落。
