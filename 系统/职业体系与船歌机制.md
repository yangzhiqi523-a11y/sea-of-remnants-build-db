# 职业体系与船歌机制（官方基准）
> 📌 来源 = 官方游戏内公告语料（`official-ingame`）。**修正**：游戏**不止四大系**，而是**六大系**（力量/智力/敏捷/魅力/**感知**/体质）。8/17 平衡重构只针对了 **力量/智力/敏捷/魅力** 四系；**感知系**（强化骰/好运）与 **体质系**（护盾生存）另成体系。

## 一、六大系 × 核心逻辑 × 职业名册（官方）
| 系 | 核心逻辑 | 官方职业 |
|---|---|---|
| **力量系** | 溅射/低体力值爆发 | 灶火英雄、大心脏暴徒、战斗狂、稳大师 |
| **智力系** | DOT + 加料/第二投/灵感 | 伺虫人(饲虫人)、灾厄虫母、焦火女、腐鸦、狂欢腐鸦、不焚火 |
| **敏捷系** | 追击(追猎)/暗影 + 额外行动 | 讨债人、首席讨债人、缠命人、异香缠命人、**海礁蚁后(蚁妈)**、红水仙 |
| **魅力系** | 正面状态堆叠 | 艺术先锋(学徒)、宠儿、纯白宠儿、麻烦精、无面放羊人 |
| **感知系** | 强化骰/好运/几率 | 钓命儿、神运钓命儿 |
| **体质系** | 护盾/生存 | 叹息之壁 |

> 注意：**船歌/往日之影/强化骰等也分系**。如 往日之影「历战军刀」(力量)、「追猎双枪」(感知)、「坚韧之盾」(体质)、「坠落之瓶」(智力)、「疾影双刃」(敏捷)、「吟游竖琴」(魅力)。

## 二、船歌 = 打"标签"来转职（关键底层）
- **船歌带"标签"**，标签数量达标才能转职（换职业）。
- 机制：以第一次转职为例，**船长先选适配的"晶骸技能"，再学习 1 条对应标签的船歌就能转职**。
- 转职所需标签数量（8/17 下调）：**II 阶 4→3，III 阶 8→6**（即 4/4/8 降为 3/3/6）。
- 因此**船歌不只是战斗增益，它决定你能否转向某职业**——选船歌 = 选构筑方向。

## 三、职业描述（官方一行版，判断"这职业干嘛的"）
- 「使我方获得更多行动，从而获得更强的输出和生存能力的辅助职业」（魅力/辅助系）
- 「可以提升友方行动值的辅助职业」（魅力系-艺术先锋→盖尔类）
- 「增多全队捣蛋时刻，运气好还能增伤的辅助职业」（感知/几率系）
- 「大幅度增加招牌技伤害的输出职业」（体质系-叹息之壁→护盾）
- 「强化骰增幅提升，且个人技也可以投掷的输出职业」（感知系-神运钓命儿）
- 「消耗积攒的护盾，造成大量伤害的输出职业」（敏捷系-红水仙）

## 四、与其他系统的关联
- **晶骸技能**：转职前先选适配的"晶骸技能"，再学对应标签船歌即转职 → 晶骸技能与船歌绑定。
- **行装/词缀、强化骰、往日之影** 均带"系"属性，构成跨系联动（详见 `四系机制与数值.md`——它聚焦 8/17 重构的四大系）。

> 判断一条构筑：① 属哪个系/职业（见上名册）→ ② 该系核心逻辑（见 `四系机制与数值.md`）→ ③ 船歌/行装/天赋是否吻合该逻辑并凑够转职标签 → ④ 对照官方更新公告数值。
