# 行装与词缀
> 版本：2026-08。最后更新：2026-08-26。

## 一、行装数据（权威·SorWiki `/equipment`）
- **收录 205 件**正式装备（名称/品质/部位/推荐属性可筛选）。
- **5 大部位**：武器、头盔、衣服、鞋子、饰品。
- **品质**：橙色、紫色、3/2/1级、**闪光**（闪光含加成倍率，属性值更高）。
- **推荐属性(主属性)**：力量、敏捷、体质、智力、感知、魅力；饰品常标**通用**。
- **词缀(固定效果，多数带 ×2 双词缀)**：溅射、护盾、受击、附加伤害、固定伤害、治疗、负面状态、持续伤害、正面状态、招牌技、额外行动、低体力值、强化骰、暴击、防御。
- **穿戴需求**：达到所列穿戴需求才完整发挥属性；属性按装备等级展示**最低值与最高值**（闪光已计倍率）。
- **筛选维度**：名称、品质、仅闪光、部位、推荐属性。
- 示例：噩梦荣光(橙·武器·体质·护盾×2)；双生匕首(紫·武器·闪光·敏捷·额外行动×2)。

## 选词缀思路（结合机制闭环）
- **输出主C**：攻强/攻击 → 暴击 → 暴伤；按主属性筛（茉莉=敏捷、小斧头=敏捷、海葬=智力）。
- **辅助**：对应系主属性 + 机制标签（盖尔=魅力/行动提前，饿猫=感知/负面）。
- **生存位**：生命/防御 + 护盾/受击（铁腕=体质）。

## 一句话
官方无独立"行装优先级"攻略页；以**上述数据 + 机制闭环** + 媒体整合作参考，数值以游戏内/SorWiki 为准。

## 通用框架
- **输出主C**：攻强/攻击 + 暴击 → 暴伤。
- **生存位**：生命/防强 + 团队增益。
- **兜底**：输出=主属性+攻击/暴伤；前排=生命/防强；用共鸣/套装对齐配队。
