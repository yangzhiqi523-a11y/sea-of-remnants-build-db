# 航海最优决策框架（局内 · 搜打撤 + 构筑）
> 🎯 这是**把"底层机制"转成"局内/养成怎么选"**的可操作决策树。数据基础=官方公告 + SorWiki。
> 先懂**构筑方向**（职业树/六系核心逻辑），再按**队伍缺口**选；一切选择**对照官方数值 + 版本时间**。

## 0. 三步心法
1. **定构筑方向**：这个位置要"机制闭环"不要"临时高数值"（机制 > 临时数值）。
2. **看队伍缺口**：主C卡哪个机制（追击/协战/DOT/溅射/正面状态…），补什么。
3. **凑标签转职**：船歌带**标签**、决定能否转职 → **选船歌=定构筑方向**，不是只挑强。

## 1. 局内「搜打撤」每一步选什么
| 阶段 | 选什么 | 决策要点 |
|---|---|---|
| **搜** | 物资/奇珍/宝箱 | 风险收益权衡：深度越大越肥越险。**按本局构筑方向取**（缺暴击=找暴击区，缺护盾=找护盾怪/祷石怪）。 |
| **构筑** | 船歌 → 行装 → 强化骰 → 技能晶骸 → 天赋 | 构成一条**闭环**：主C机制 → 标签转职 → 词缀/骰补漏 → 天赋叠核心。 |
| **打** | 站位/目标 | 让**机制生效**：协战C=保高攻队友多动；DOT=叠满层再引爆；盾坦=套盾给受击者。 |
| **撤** | 返航 | 收益锁定；成型前的**贪心上限**=本局目标已达成即撤。 |

## 2. 构筑方向速查（六系核心逻辑 → 最优闭环）
| 系 | 核心逻辑 | 最优闭环 | 代表角色 |
|---|---|---|---|
| **敏捷** | 追击(追猎)/额外行动 + 暗影 | 高频攻击触发追击 → 叠暗影/印记 → 爆发 | 茉莉(协战/共演)、小斧头(玫瑰印记) |
| **智力** | DOT + 加料/第二投/灵感 | 叠持续伤害满层 → 引爆/立即结算 → 群AOE | 海葬(往生蝶/安魂舞)、腐鸦/灾厄虫母 |
| **力量** | 溅射/低体力值爆发 | 溅射扩散 → 低体力值增伤爆发 | 灶火佬/大暴头、红水仙(护盾转伤) |
| **魅力** | 正面状态/行动提前/治疗 | 攒资源(根音) → 行动提前+增伤+群体续航 | 盖尔(艺术先锋/牧羊犬) |
| **感知** | 强化骰/好运/固定伤害 | 强化骰掷点 → 几率增伤/固定伤害 | 饿猫(爪痕/负面易伤)、钓命儿 |
| **体质** | 护盾/生存/嘲讽 | 套盾 → 挡伤/嘲讽 → 反击/护盾转伤 | 铁腕(守护之壁/戍卫铁拳) |

## 3. 你box建设方向（当前8/17后）
- **茉莉（主C·敏捷·协战双核）**：个人技[共演]给**最高攻+多动**队友 → 队友攻击必触发茉莉协战；集中**叠暗影+暴击**放大协战。招牌技也视为协战、吃同套增益。
  - 选：船歌=协战/暗影/暴击 标签；行装=敏捷+攻/暴击/暴伤；强化骰=输出增伤向(聚浪/蝶陨/鲸涛)；往日之影=安眠人偶。
- **铁腕统领（生存·体质·盾坦）**：敌动前给受击友军套守护之壁 → 护盾被消耗+嘲讽主目标 → 反击补伤。体力上限优先。
- **小斧头（敏捷·印记单体）**：玫瑰追猎追击 → 叠6层印记 → 招牌清空爆发，残血保链。
- **盖尔（魅力·辅助）**：攒根音 → 个人技耗3层治疗 / 招牌拉条；注意能否跨5层触发点。
- **饿猫（感知·追击易伤）**：负面丰富队 → 爪痕按负面数增伤 → 满层鱼骨脆了集火。
- **海葬（智力·群AOE）**：散怪快速积往生蝶 → 5层触发个人技免费招牌；多波次关强。

## 4. 决策校验（排毒）
一条构筑/攻略，上市前必查：
- ① 属哪个系/职业（见 `职业体系与船歌机制.md` 职业树）→ ② 该系核心逻辑是否吻合（见 `四系机制与数值.md` 8/17数值）→ ③ 船歌/行装/天赋是否凑够**转职标签**并闭环 → ④ **对照官方更新公告数值 + 发布时间**，可疑标"待实测"。
> 社区"毒攻略"多不标版本、夸大数值；对不上官方就作废。
