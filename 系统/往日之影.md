# 往日之影
> 📌 来源：SorWiki 数据站 `/shadows`（社区数据，需对照官方验真）。**记忆/碎片/镶嵌/共鸣**具体机制见详情页。

## 是什么
装备在角色上的**记忆碎片**（往日之影），提供**体能/词条/共鸣**加成；按**稀有度 + 属性 + 关联船员**筛选。

- **稀有度**：黑券 / 紫券 / 蓝券。
- **属性(6系)**：力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力。
- **满级体力**（按稀有度）：黑券 2300–4160；紫券 2145–2850；蓝券 1860。
- 每项标注「关联船员」或「属性通用」。
