# 游戏是什么 · 怎么玩 · 怎么选
> 🧭 **先看这页建立整体认知**，再去读角色/配队/build。版本锚点：2026-08（8/17 首赛季平衡重构）。数据以游戏内 + 官方公告 + SorWiki 数据站为准。
> 数据源：官方游戏内公告(最权威) + SorWiki(sorwiki.com 数据图鉴) + 社区玩法视频(用于"怎么选/操作"，需对照官方)。

## 一句话
《遗忘之海》= 网易**海洋开放世界**冒险，核心 = **航海「搜打撤」** + **肉鸽局内构筑** + **回合制六系职业战斗**，外加长线养成与多端互通（手机/PC/PS5）。

## 核心循环（最重要）
**出海 → 👀搜 → 🎲构筑 → ⚔️打 → ⛵撤**
1. **出海**：驾船离开主城（奥托皮亚）进入海域/岛屿。
2. **搜**：探索、搜刮物资/奇珍/宝箱（越深入越肥也越险）。
3. **构筑（局内肉鸽）**：每次出海=一局「**遗忘之旅**」，局内选 **船歌 / 行装 / 强化骰 / 技能晶骸 / 天赋** 构筑这一局。
4. **打**：回合制战斗，用**六系职业**（力量/敏捷/体质/智力/感知/魅力）打敌怪/Boss。
5. **撤**：返航带走收益。核心是**风险收益权衡**（搜得越深越贪，收益越高、翻车越险）。
> 之上再叠 主线推进、长线养成（船员/职业/船/黑券）、高难（大记忆之塔/噩梦深潜）与**冲榜**（"好梦杯"等）。

## 玩法模块
- **大世界海洋** + **主城**（奥托皮亚）+ **岛屿**（隐秘海：石像岛/密林岛/溪流岛/虫岛/佳酿溶洞；还有 渡桥岛/白沙海）+ **小游戏**。
- **肉鸽局内**：遗忘之旅（每局随机构筑）。
- **回合制战斗**：六系职业。
- **高难**：大记忆之塔、噩梦深潜/无尽梦魇（含好梦杯大赛）。

## 职业体系（六系 · 权威·SorWiki）
按**六维属性**分系，每系是「**I阶基础 → II阶分支 → III阶高阶**」三级树（I阶上限5级，II/III阶上限10级）。**转职**需"前置职业 + 标签数 + 职业任务"；7/23 后标签要求 **4/4/8→3/3/6**（得3标签转II阶、6标签转III阶）。每个 II/III 阶分支占一个机制标签，逐级强化。

| 系 | I阶基础 | II阶分支(机制标签) |
|---|---|---|
| **力量** | 战斗狂学徒 | 大暴头(低体力值)/灶火佬(溅射)/稳老头(护盾) |
| **敏捷** | 独行客学徒 | 蚁妈(招牌技)/缠命人(暴击)/讨债人(额外行动)/水仙(负面状态) |
| **体质** | 忠卫学徒 | 狮心者(受击)/铁壁(护盾)/笨壳(防御) |
| **智力** | 狂想家学徒 | 腐鸦(持续伤害)/焦火女(强化骰)/饲虫人(额外行动) |
| **感知** | 机灵鬼学徒 | 蜜丸(负面状态)/钓命儿(强化骰)/重炮(固定伤害) |
| **魅力** | 艺术先锋学徒 | 牧羊犬(行动提前)/麻烦精(附加伤害)/灵医(治疗)/宠儿(正面状态) |

> 已开放部分 III 阶：稳大师、海礁蚁后(蚁妈)、红水仙、叹息之壁、不焚火、神运钓命儿。→ 详见 `系统/职业体系与船歌机制.md`。

## 怎么选（构筑选择逻辑 · 局内 + 养成）
> 游戏是**肉鸽**，没有"官方指定职业"；**怎么选 = 看构筑闭环 + 当前目标**。
- **选系/职业**：先定角色，看可学节点，按**队伍缺口**选分支；资源紧时集中养一名主力，**勿平分标签**。
- **选船歌**：船歌带**标签**、决定能否转职 → **选船歌 = 定构筑方向**（不是只挑强的）。按你想要的机制标签（暴击/溅射/强化骰/行动提前/额外行动/正面状态…）选。208首图鉴见 `数据/船歌图鉴.md`。
- **选行装/词缀**：按**主属性**（角色六维最高者）+ 队伍定位筛选；词缀补构筑缺口。
- **选强化骰**：强化骰=掷点/强化点，配合**职业技能**；不同骰适配不同技能类型（见 `系统/强化骰.md`）。
- **选天赋/头脑强化**：按核心机制堆（如茉莉堆[协战]增伤/暗影/暴击；DOT系堆加料/灵感）。
- **择时**：开荒=容错/生存优先；成型=补齐核心机制；**冲榜**=极限数值（按官方8/17后数值）。

**典型例子（茉莉）**：协战双核主C——把个人技[共演]给**最高攻+多动**队友，队友攻击→茉莉必协战；集中**叠暗影+堆暴击**放大协战。选船歌/行装/强化骰都围绕"协战增伤/暗影/暴击"闭环。
> 社区"毒攻略"多不标版本、夸大数值；**一律先对照官方公告数值(SorWiki/本库) + 发布时间**，对不上就标"待实测"。

## 养成线（长线）
船员(角色) → **六系职业/转职** → 天赋(头脑强化) → 船歌 → 行装/词缀 → 强化骰/技能晶骸 → 船只改装/船首像 → 往日之影 → 黑券(招募/六选一)。→ 详见各 `角色/`、`系统/`、`数据/` 页。
