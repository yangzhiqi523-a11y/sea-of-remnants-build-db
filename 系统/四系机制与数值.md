# 四系机制与数值（官方基准）
> 📌 **底层逻辑权威基准**。来源 = 官方 **8/17 首赛季平衡重构**公告原文（`official-ingame`，本机游戏公告）。数值**是官方原文**，是判断"构筑是否成立/是否过时"的基准。
> 四系：**力量 / 智力 / 敏捷 / 魅力**（每系设计逻辑不同，相互之间通过 船歌/行装/天赋 交叉联动）。

## 一、四系核心逻辑（一句话）
- **力量系**：**溅射(AOE)** 引擎。靠"溅射"连环清场，低体力值换高伤害。
- **智力系**：**持续伤害(DOT) + 加料/第二投** 引擎。靠"加料/灵感"叠毒叠伤；与魅力系辅助契合度在 8/17 被补齐（DOT 倍率可受"技能伤害倍率提升"加成）。
- **敏捷系**：**追击(追猎)/暗影 + 额外行动** 引擎。靠消耗"暗影"触发"追猎"追击，多动叠暗影白嫖额外行动/大招。
- **魅力系**：**正面状态堆叠** 引擎。靠"正面状态"标签数量触发增伤（华丽谢幕等）；8/17 把极端堆叠收敛到合理区间。

## 二、力量系（溅射）
- **灶火英雄** 职业被动「燎原」：攻击后每有一敌受「溅射」计数+1（同目标仅1次），累计 **12** 触发「**火上浇油**」（对随机敌再用该技能，本次技能 35% 溅射，额外造成上次总溅射伤害的 **24%**(原10%)），随后清空计数。
- **大心脏暴徒** 被动「猩红盛宴」：每损失1%体力→额外+0.3%伤害；场上每有1个体力<75%的单位→伤害+**30%**(原10%)；行动开始令全员失去自身体力上限10%（其他至少保留70%）。低体力标签»8>10>12>14→伤害+10%>20%>30%>40%（原5>10>15>20）。
- 关键天赋：**四溅的火星**（火上浇油击败/单次>15%最大体力→再造成该次70%溅射）；**灰烬新生**（燎原所需计数-7，每回合仅1次火上浇油）；**借风助燃**（触发火上浇油获1层借风，4层时触发火上浇油倾倒记录伤害）；**引燃**（溅射把敌降至50%体力也触发火上浇油，本次伤害-65%）；**开胃菜**（任意单位损失1%体力→+0.03%暴击率+0.06%暴伤，至多9%/18%；有单位<75%则效果×1.5）；**同生共逝**（自身攻击额外对主目标造成本回合全员消耗体力80%伤害）。
- 船歌：**一地金花**（击败/击破→全体溅射，总伤害为主目标75%(原50%)，均分）；**灶火上不会有冷饭**（用船员技能额外40%溅射；技能自带溅射则溅射+30%(原24%)）；**勇敢小调**（每用1强化骰本次攻击+10%(原7%)溅射）。

## 三、智力系（DOT + 加料/第二投）
- **机制**：8/17 让 **DOT 基础倍率、船歌/角色被动/职业天赋的结算伤害倍率都可受「技能伤害倍率提升」加成**（补强 DOT+辅助契合）。
- **伺虫人** 被动「啃噬本能」：触发「加料」后触发「**第二投**」对主目标再用同技能、同倍数加料，该技能伤害+**35%**(原-30%)；1回合1次。「虫群围猎」60%→改为主目标及两侧 **50%** 伤害，自身+1灵感，每命中1敌再+1灵感。
- **灾厄虫母** 被动「掠食恶习」：用船员技能40%概率耗1灵感触发1倍加料+第二投（第二投伤害+35%）。天赋「蛰伏」：触发第二投后 **40%**(原15%) 再触发第二投。「速生的卵」：加料概率+15%、加料伤害+10%。“显眼猎物”：自身每10%效果命中→额外行动伤害+8%，至多80%。
- **焦火女**「暴烈烟花」：敌全体攻击力60%伤害，本次加料概率+10%(原5%)，伤害+25%(原5%)。
- **腐鸦**「假意回馈」：敌全体攻击力50%，(80%+效果命中20%)概率给主目标随机2层持续伤害；主目标每1层持续伤害伤害+1%，至多 **50%**(原20%)。

## 四、敏捷系（追击/暗影 + 额外行动）——★ 茉莉所在系
- **讨债人** 被动「清算条款」：每累计消耗 **12** 层「暗影」发动「追猎」；自身每次行动累计1层暗影消耗；最终伤害额外行动增伤30%。「**追猎**」：对主目标造成攻击力 **240%**(原140%) 额外行动伤害。
- **缠命人**「绝不手软」：攻击力 **45%**(原37.5%)×骰数 + **180%**(原150%)，**暴击抗性下降 骰数+1 级(原+3)**，持续3回合。「溃伤感染」：每层暗影使拥有者**暴击抗性降低 0.3%**(原0.5%)。
- **异香缠命人**「复仇日」：暴击时目标为散怪且体力<50% → **20%**(原10%) 概率力竭；非散怪额外造成该伤害 **1倍**(原1.5倍) 暴伤。「强韧意志」：暴击率固定 **40%**(原30%)，暴击50%概率力竭，非散怪额外 **2倍**(原3倍) 暴伤。
- **首席讨债人**「夜行消迹」：回合开始追击伤害+15%(原6%)，每次追击再+15%(原6%)，1回合4次。「讨罪决」：敌受2次追猎→消耗其3层暗影使下次追猎伤害+85%。「双匕留影」：追猎造成攻击力 **45%**(原30%) 多次伤害，次数=目标已受追猎次数，至多 **5次**(原4次)。
- **蚁妈**「先机急动」：目标体力< **60%**(原50%) 时伤害+**20%**(原10%)。
- **红水仙** 被动「华美的宫廷礼」：我方攻击拥有「心碎」的主目标时，发动我方攻击力 **50%**(原30%) 的「暗影刃」（无法施加心碎）。
- **茉莉**以敏捷系为核心（追击/暗影 + 额外行动），走 **缠命人 → 异香缠命人** 或 **蚁妈大招流**（详见 `角色/茉莉.md`）。

## 五、魅力系（正面状态）
- **纯白宠儿** 被动「狂欢之日·华丽谢幕」：攻击力+3%，每有一正面状态再+1%，**至多统计40个**；标签»8>10>12>14→额外+0.25%>0.5%>0.75%>1%（原0.5>1>1.5>2），正面状态生效个数上限45>50>55>60。
- **麻烦精**「音符回响」：「热情」每次达记数值上限30%→全体攻击力+3%（最多3个），自身附加伤害+5%（最多3个）。
- **宠儿**「鼓舞之音」：「盛大开场」生效时，我方技能造成附加伤害则+4%附加伤害（至多5个），盛大开场结束清除。

## 六、强化骰 / 装备 / 祷石（8/17）
- 强化骰「**腐牙骰**」：用技能后为敌全体施加「腐坏」2回合并召唤「腐牙」。腐坏：持续伤害结算后每1点骰子点数造成攻击力 **15%**(原10%) 伤害，每掷出1个6倍率+30%(原20%)，至多叠3层；腐牙：初始速度0，敌每结算1次行动+25%。
- 装备「爱意永不凋谢」：主属性「效果命中」→「伤害提升」。
- 祷石「安枕金堆旁」：失落海域每 **300**(原1000) 旧金币→攻击+0.5%、防御+0.5%，至高叠20层。富裕/奢侈/安枕/提神/香水祷石可在噩梦深潜生效。

## 七、往日之影 / 船只 / 船员修复速览
- 往日之影「安眠人偶」片段1「裁缝铺」、「文明法则」片段3「蛛网玫瑰」、「疾风之步」片段3「步伐」= 最终暴伤提升类。
- 船只「流浪烟花号」船首像守护「效果有保证」「腐蚀它」= 提升「引爆」伤害。
- 船员：小斧头「无声的墓悼」(额外行动增伤)、跟屁虫秘闻5「少年气自盛」(暴伤)、焦面对接、疫虫/连戮回势/溃心战法等敏捷天赋修复。

## 八、交叉联动逻辑（底层）
- **敏捷×船歌×行装**：追猎(追击)吃"额外行动增伤"船歌/词缀；暗影层数吃暴击抗性；"行动提前/额外行动"越多，叠暗影越快→追猎越频繁。
- **智力×魅力**：DOT 倍率 + 技能伤害倍率提升（8/17 后）→ 持续伤害职业配魅力系"正面状态/增伤"辅助才有意义。
- **力量×船歌**：溅射% 靠船歌/天赋堆叠，一网打尽清场。
- **魅力×天赋**：靠职业天赋稳定"产出正面状态"，避免只能靠极端堆叠。

> 判断一条构筑"成不成立"，先按这套**官方数值**对照当前版本，再结合角色/职业/船歌/行装/天赋的**交叉相乘**；**航海(局内)选择看你的构筑闭环**，不是单点最强。
