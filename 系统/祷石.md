# 祷石
> 📌 来源：SorWiki 数据站 `/prayer-stones`（社区数据，需对照官方验真）。

## 是什么
可装备/搭配的**增益道具**，共收录 **82 颗**；分**基础效果**与**满足感召条件后触发的额外效果**。多为随机掉落，部分为**指定怪/地图掉落**。

- **感召属性**：通用·56 / 力量·6 / 敏捷·6 / 体质·4 / 智力·5 / 感知·2 / 魅力·3。
- **品质**：橙色·20 / 紫色·31 / 蓝色·31。

## 指定掉落（重要：祷石=长期可刷目标）
- 「安枕金堆旁」＝黄金巨蟹专属（旧金币→伤害提升）。
- 「林间的守望」＝溪流岛·铁翎巨枭。
- 「摇滚之魂不灭」＝海湾岛·摇滚巨蟹。
- 「如海晶绚丽」＝回音岛·人鱼。
- 「全体进攻信号」＝随机掉落。
