# 出海玩法与进阶
> 版本：2026-08。最后更新：2026-08-26。

## 一句话
核心循环 = **出海—探险/寻宝—回港养成—再出海**，带「周目重置 / 死了就失忆」的 Roguelite 风险机制：**出海越深风险越高、收益越大**。

## 要点
- **出海前做生存预算**：带足补给 + 明确目标 + 设止损。社区实测锚"约200个炮就得返航"——仅个体经验，无官方数据。
- **高危本（深渊困难三 / 隐秘海）重阵容/词缀/机制应对，不无脑堆战力**。
- **成型期必做**：清每日/周常上限、船只改装、投资船员战力、规划航海团委托与出海顺序。
