# 可信攻略库

用途：记录经遴选、带版本与可信度的可信来源，供撰写角色 / 系统页时引用。

## 可信度分层
| 层 | 含义 | 示例 |
|---|---|---|
| `official` | 官方原文 | cg.163.com 官方公告/攻略页、官方 TapTap 发布、项目组来信 |
| `official-repost` | 官方公告正规转载 | 4399 / 3DM / 17173 / 233乐园 等 |
| `media` | 媒体原创攻略 | 17173 / 九游 / ali213 / 18183 / 豌豆荚 等 |
| `community` | 自媒体 | B站专栏/动态、TapTap 玩家动态、搜狐、W12Z 等 |

## 权威来源（高权重，固定速查）
- 官网公告 / 攻略页：`cg.163.com/static/content/<hash>`（官方原文，最高权重）
- 官方 TapTap 发布（版本更新、项目组来信）
- 官方公告正规转载：4399 / 3DM / 17173 / 233乐园

## 版本纪律
- 结论必须带**版本日期**；`8/17`（首赛季平衡重构）前的强度/加点/配队攻略视为"过期候选"。
- 引用时注明层别与日期，避免"无版本引用"。
