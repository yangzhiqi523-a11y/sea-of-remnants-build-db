**出海「搜打撤」**：出海 → 搜（探索/搜刮）→ 局内构筑（船歌/行装/强化骰/技能晶骸/天赋）→ 打（回合制**六系**职业战斗）→ 撤（返航带走收益）。核心是**风险收益权衡**；其上层再叠加长线养成与冲榜。**完整认知见 `系统/游戏是什么与怎么玩.md`**。
