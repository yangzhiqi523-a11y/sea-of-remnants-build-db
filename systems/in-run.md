# 局内机制（遗忘之旅 / 逐浪计划）
> 版本：2026-08。⚠️ 本页为**框架级**，数值待补。

## 一句话
局内养成含「**四大核心资源、强化骰、晶骸**」，与旅人技能、天赋、船歌共同构成单局。**资源集中投到最能放大本体系收益的一点，别平均分。**

## 决策优先级（出海时对照）
1. **主C（茉莉）**：招牌技 / 追击 / 溅射相关的骰与技能先给。
2. **行动链（小斧头）**：拉追击 / 溅射发动频率。
3. **坦克（铁腕统领）**：保命。
4. **辅助**：最后。
