# 船养成
> 版本：2026-08。最后更新：2026-08-26。

## 一句话
船只改装是成型期收益放大的关键。**先升直接加战力的模块，工具性模块成型期再补。**

## 研究结论（采集自公开来源）
- 改装优先级：先升**船体 / 主副炮 / 船首像 / 桅杆**（加攻击/生命/防御/舰队属性），冲榜期把输出+生存模块拉满。
- 航行 / 探索 / 知识类工具模块放到成型期再补，避免资源分散。
- 来源：《[船只改装全攻略](https://a.9game.cn/yiwangzhihai/11973820.html)》《[船只改装玩法详解](https://a.9game.cn/yiwangzhihai/11970443.html)》(media)。
