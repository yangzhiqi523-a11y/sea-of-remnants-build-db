# 天赋系统
> 版本：2026-08（以 8/17 首赛季平衡重构为当前基线）。最后更新：2026-08-26。

## 一句话
天赋属于"角色 / 职业纵向养成"，与**标签(tags) + 转职 + 信物**体系绑定。天赋与技能、行装词缀、船歌、配队共同决定成型战力。

## 研究结论（采集自公开来源，非定论）
- 底层机制：【官方·角色养成详细攻略·新手避坑】(https://cg.163.com/static/content/6a4777a91fce6e971ac80f33)（official）、【标签与转职系统介绍】(https://shouyou.3dmgame.com/gl/630489.html)（official-repost）。
- 加点逻辑（成型 / 冲榜）：集中投资主C「招牌技 + 追击/溅射加成 + 暴击/攻速」，生存/辅助其次。
- 天赋点来源/规划：【官方·奥普港养成·资源分配】(https://cg.163.com/static/content/6a828668982fc7b35f001206)（official）。
> 具体节点名、加点数值、洗点成本待当前版本实测核对。

## 实操要点
- 主C先点招牌技与追击/溅射，再点生存与辅助。
- 泛用兜底：主C未定时用「通用输出 + 保命」均衡加点。
