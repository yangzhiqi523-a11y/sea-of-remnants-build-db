# 出海日志

每次出海记录一份，用 `出海日志模板.md` 模板。文件命名：`出海日志/YYYY-MM-DD-<海区>.md`。

## 记录要点
- 永久选择 / 临时物品 / 天赋 / 技能 / 骰子
- 规避的失误
- 下一个优先

## 为什么记
长期积累形成"什么抉择在**什么版本 / 什么环境**最赚"的真实数据库，配合 `角色/`、`数据/当前基线.md` 使用。

## 航海抉择速记（出海时对照）
- 技能 / 强化骰 / 局内资源优先给**主C（茉莉）**，再补行动链（小斧头）与辅助。
- 行装 / 词缀：主C 攻强/攻击→暴击→暴伤；前排（铁腕统领）生命/防强。
- 船只：先升加战力的模块（船体 / 主副炮 / 船首像 / 桅杆）。
